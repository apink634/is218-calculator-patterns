# Basic rubric — 100 points

| Category | Points | Full-credit requirements |
| --- | --- | --- |
| Working CLI | 30 | Four correct operations, useful errors, continued input, history, exit, and EOF. |
| OOP and patterns | 30 | Static operations; ABC with required execute(); inherited class factory; instance execution; selected operation strategy; calculation and history commands. |
| Tests and coverage | 20 | Meaningful tests pass; all application code is measured; 100% line coverage with explained, appropriate exclusions. |
| GitHub Actions | 10 | Committed workflow runs on pushes and pull requests, enforces 100%, and latest submitted run passes. |
| STUDENT_README.md, comments, and submission | 10 | Accessible repository, working instructions, concise OOP/SOLID/pattern explanations, useful comments, and Actions link. |

Full credit in each category means its requirements are met. For small issues, deduct 1–3 points within that category; for a substantial missing or broken part, deduct 5–10 points. If a category has no work, award 0 for that category. Deduct for a problem once, in the most relevant category. Do not deduct for personal naming or formatting preferences. A missing submission or repository with no meaningful assignment work receives 0 overall. The 100% coverage requirement is mandatory for full credit in the tests category; falling short does not automatically make the entire assignment a zero.

## Check before submitting

- [ ] All four operations work with positive, negative, decimal, and zero values (except division by zero).
- [ ] Unknown commands, wrong operand counts, invalid numbers, and division by zero show helpful messages. A later valid command still works.
- [ ] Successful history stays in order; failures are not recorded; viewing history returns a copy.
- [ ] Exit and EOF stop cleanly.
- [ ] Static operations, the calculation ABC, inherited class factory, instance execute method, selected strategy, and both command classes are present.
- [ ] Meaningful tests pass with 100% line coverage across calculator; exclusions are small and explained.
- [ ] The latest Actions run passes for the submitted code.
- [ ] STUDENT_README.md contains commands, examples, method/pattern/OOP/SOLID explanations, exclusions, and the successful run link.
- [ ] Work is pushed, the instructor can access it, and Canvas contains my own repository URL.

The rating buttons are examples of partial credit. Instructors may enter intermediate points in the category score field. No particular naming or output wording is required if the behavior is correct and readable.
